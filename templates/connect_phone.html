Setup Guide (5 minutes)
A
Phone Settings
Install Health Connect from Play Store (Android 14+: Settings → Security → Health Connect).
In Google Fit: Profile → Settings → Health Connect → turn on.
B
Same Wi-Fi Network
Phone and PC must be on the same Wi-Fi. For remote access, run ngrok http 5000 and use the https URL.
C
Install Android App
Open Android Studio → File → Open → select the android/ folder in this project. Click Run.
D
Pair & Allow Permissions
In the app, paste the server address and the pairing code above. Tap Save, then Allow Health Connect access, then Sync now.
5
Done!
The status above should change to Connected within 5 seconds of tapping Sync now.
